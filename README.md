Flappy Bird Clone

Game web berbasis Phaser 3 / HTML5 yang telah dimodifikasi dengan penambahan fitur transisi level, penyesuaian tingkat kesulitan, dan sistem pencatatan skor terbaik.

---

Fitur & Modifikasi Level

Berikut adalah beberapa modifikasi dan fitur yang ditambahkan ke dalam game:

1. **Transisi Multi-Level / Background**: Perubahan visual latar belakang secara dinamis seiring bertambahnya skor pemain.

2. **Difficulty Scaling**: Peningkatan kecepatan rintangan/pipa seiring berjalannya permainan untuk meningkatkan tantangan.

3. **Best Score Tracking**: Menyimpan skor tertinggi pemain ke dalam LocalStorage browser agar tidak hilang saat reload.

---

Cara Bermain & Kontrol

* **Spasi / Klik Kiri / Tap**: Membuat burung terbang/melompat ke atas.

* **Tujuan**: Lewati sebanyak mungkin pipa tanpa menabrak pipa atau jatuh ke tanah untuk mendapatkan skor tertinggi.
